# MAX Chat

Тестовое задание — пользовательский интерфейс для отправки и получения текстовых сообщений в MAX через GREEN-API.

## Возможности

- Авторизация по `idInstance` и `apiTokenInstance`
- Создание чата по номеру телефона получателя
- Отправка текстовых сообщений
- Получение входящих сообщений
- Отображение истории сообщений в интерфейсе чата

Авторизационные данные хранятся только в памяти приложения и сбрасываются при перезагрузке страницы.

## Технологии

- React
- TypeScript
- Vite
- Hono
- GREEN-API
