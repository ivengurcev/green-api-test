# MAX Chat

Тестовое задание — пользовательский интерфейс для отправки и получения текстовых сообщений в MAX через GREEN-API.

## Тестовое задание

В рамках тестового задания требуется разработать пользовательский интерфейс для отправки и получения сообщений через GREEN-API.

Исходное задание предполагает работу с мессенджером MAX, но также допускает реализацию для WhatsApp или Telegram.

**В данном проекте используется WhatsApp.**


### Требования

1. Разработать пользовательский интерфейс для отправки и получения сообщений.
2. Использовать сервис [GREEN-API](https://green-api.com/).
3. Реализовать отправку и получение только текстовых сообщений.
4. За прототип интерфейса взять внешний вид чата [MAX](https://web.max.ru/).
5. Реализовать интерфейс с максимально простым и минимальным набором функций.
6. Отправку сообщений реализовать методом [SendMessage](https://green-api.com/docs/api/sending/SendMessage/).
7. Получение сообщений реализовать через [HTTP API GREEN-API](https://green-api.com/docs/api/receiving/technology-http-api/).
8. Использовать React.

### Ожидаемый результат

- Пользователь переходит на сайт чата и вводит свои учетные данные GREEN-API:
  - `idInstance`
  - `apiTokenInstance`
- Пользователь вводит номер телефона получателя и создает новый чат.
- Пользователь пишет текстовое сообщение и отправляет его получателю в WhatsApp.
- Получатель отвечает на сообщение в WhatsApp.
- Пользователь видит ответ получателя в интерфейсе чата.

### Реализация

Для взаимодействия с WhatsApp используется GREEN-API.

Приложение обращается к GREEN-API напрямую из браузера, без собственного backend. Обоснование решения, его ограничения и риски описаны в документе [«Почему приложение работает без backend»](docs/frontend-only-architecture.md).

Отправка текстовых сообщений выполняется методом `SendMessage`.

Входящие сообщения получаются через HTTP API с использованием методов `ReceiveNotification` и `DeleteNotification`.

## Возможности

- Авторизация по `idInstance` и `apiTokenInstance`
- Создание чата по номеру телефона получателя
- Отправка текстовых сообщений
- Получение входящих сообщений
- Отображение истории сообщений в интерфейсе чата

Авторизационные данные хранятся только в памяти приложения и сбрасываются при перезагрузке страницы.
