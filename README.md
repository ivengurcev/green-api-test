# WhatsApp Chat

Фронтовое тестовое задание: минимальный React-интерфейс для отправки и получения текстовых сообщений WhatsApp через GREEN-API. Внешний вид основан на веб-интерфейсе MAX, но API MAX и WABA в проекте не используются.

Приложение обращается к GREEN-API напрямую из браузера, без собственного backend, proxy или BFF. Компромиссы и риски этого решения описаны в документе [«Почему приложение работает без backend»](docs/frontend-only-architecture.md), полное ТЗ и критерии приёмки — в [MVP-требованиях](docs/mvp-requirements.md).

## Возможности MVP

- проверка `idInstance` и `apiTokenInstance` через `GetStateInstance`;
- создание одного активного чата после `CheckWhatsapp`;
- отправка текста через `SendMessage`;
- последовательное получение `textMessage` и `extendedTextMessage` через `ReceiveNotification` / `DeleteNotification`;
- адаптивные desktop- и mobile-представления от ширины 320 px;
- отменяемый polling, дедупликация уведомлений и повторные попытки с backoff.

Реквизиты, активный чат, черновик и сообщения хранятся только в памяти вкладки. Новый успешно проверенный чат заменяет предыдущий, а перезагрузка страницы полностью очищает сессию.

## Подготовка GREEN-API

Перед запуском нужен собственный инстанс GREEN-API:

1. Подключите к нему аккаунт WhatsApp и дождитесь состояния `authorized`.
2. В настройках инстанса включите получение входящих сообщений — `incomingWebhook`.
3. Оставьте `webhookUrl` пустым: приложение самостоятельно читает очередь через HTTP API.
4. Не запускайте несколько потребителей одной очереди одновременно — другая вкладка или клиент могут забрать уведомление первыми.

## Локальный запуск

Требуется Node.js и pnpm.

```bash
pnpm install
pnpm dev
```

После запуска введите `idInstance` и `apiTokenInstance` в форме входа.

Для удобства локальной разработки значения можно задать в игнорируемом Git файле `.env.development.local`:

```dotenv
VITE_GREEN_API_ID_INSTANCE=your-id-instance
VITE_GREEN_API_TOKEN_INSTANCE=your-api-token-instance
```

Переменные `VITE_*` попадают в клиентский bundle и не являются защищённым хранилищем. Используйте их только локально и не добавляйте реальные реквизиты в Git.

Полная автоматическая проверка:

```bash
pnpm check
```

Команда последовательно запускает TypeScript, тесты и production-сборку.

## Ограничения

- только один активный личный чат;
- только текстовые сообщения и текст со ссылкой;
- история существует только в текущей сессии;
- нет групп, медиа, статусов доставки и загрузки прошлой истории;
- frontend-only схема раскрывает токен выполняемому в браузере коду и зависит от CORS GREEN-API.

## Технологии

React 19, TypeScript, Vite, CSS Modules, Vitest, Testing Library и Fetch API.
